## English

**All code, documentation and promo art in this project were written by an AI assistant (DeepSeek).**

The author (the person publishing this) **does not write code**. What he did:

- set the requirements (what should happen, what was wrong);
- **made the design calls** (dropping the mimic animation, the tint colours, whether the slime's body is
  removed, which platforms to publish on);
- **tested every build in the real game**, and reported failures with screenshots and logs;
- **owns the release** - this repository and these builds are published under his name.

So: **the code was written by an AI, the requirements and acceptance were human.** That is not a
disclaimer, just an accurate description of who did what.

If you find a bug, please do report it. Be aware that diagnosis and fixes are also AI-assisted and may
need your BepInEx log (BepInEx/LogOutput.log) to locate the cause, because the author cannot read the
code directly.
