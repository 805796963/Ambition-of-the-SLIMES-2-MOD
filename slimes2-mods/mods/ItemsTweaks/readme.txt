# 道具强化 / Item Tweaks

## 中文
把 ItemsTweaks.dll 放进 <游戏目录>\BepInEx\plugins\，需要 BepInEx 6（IL2CPP）。
配置：BepInEx\config\dsh.ambition.slimes2.itemstweaks.cfg。
通关奖励发放全部道具、解除道具次数限制、变身道具对任意史莱姆可用、单位箱容量可调（默认同原版）。

## English
Drop ItemsTweaks.dll into <game>\BepInEx\plugins\. Requires BepInEx 6 (IL2CPP).
Config: BepInEx\config\dsh.ambition.slimes2.itemstweaks.cfg.
All items from a stage clear, no item budget per slime, transform on any slime, configurable box size.
