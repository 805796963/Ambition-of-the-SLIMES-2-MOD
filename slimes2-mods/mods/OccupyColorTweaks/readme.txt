# 占领解放 / Occupy Tweaks

## 中文
把 OccupyColorTweaks.dll 放进 <游戏目录>\BepInEx\plugins\，需要 BepInEx 6（IL2CPP）。
配置：BepInEx\config\dsh.ambition.slimes2.occupycolor.cfg。
解除占领限制（护盾机制保留）+ 修复强制占领后的显示 + 可选阵营染色（默认关）。
