# 史莱姆大修 / Slime Fix

## 中文
把 SlimeFix.dll 放进 <游戏目录>\BepInEx\plugins\ 即可，需要 BepInEx 6（IL2CPP, bleeding-edge）。
首次启动后配置生成在 BepInEx\config\dsh.ambition.slimes2.slimefix.cfg。
包含：继承次数 999、太阳属性附身改属性、杂鱼掉落本体（每场一次）、溶解史莱姆消化出骷髅、分裂两代。

## English
Drop SlimeFix.dll into <game>\BepInEx\plugins\. Requires BepInEx 6 (IL2CPP, bleeding-edge).
Config is generated at BepInEx\config\dsh.ambition.slimes2.slimefix.cfg on first launch.
Contains: inherit uses 999, sun possession changes the host attribute, zako body drop (once per battle),
melty digest into a skeleton, two generations of splitting.
